# 健康数据记录

📱 纯 HTML 离线应用 - 手机版和电脑版分开，无需安装任何应用！

## 📂 文件说明

- `mobile.html` - **手机版**：底部 TabBar 导航 + 单列卡片，适合手机屏幕
- `desktop.html` - **电脑版**：顶部导航 + 宽屏多列布局 + 大图表，适合电脑
- `README.md` - 本说明文件

> 两个文件**功能完全相同**、数据格式完全一致（同一套千问 API 逻辑），可互相导入导出数据。

## 🎯 主要特性

- 🌐 **纯前端单文件**：各自一个 HTML 搞定，无需服务器、无需 Python 后端
- 🔑 **单密钥配置**：只用一个千问 API 密钥完成图片识别 + 数据抽取
- 📊 **完整功能**：体重 / 饮食 / 运动录入、统计图表、趋势分析
- 📤 **多种导出**：JSON 备份（可无损回导）、HTML 报告（双击即可查看）
- 🎨 **多主题**：浅色 / 深色 / 护眼

## 🚀 使用方法

### 1. 手机版
1. 将 `mobile.html` 发送到手机（微信、邮件等）
2. 用手机浏览器打开
3. 「⚙️ 设置」配置千问 API 密钥后开始记录

### 2. 电脑版
1. 双击 `desktop.html` 用浏览器打开（宽屏桌面布局）
2. 同样只需配置一次千问 API 密钥

### 3. 手机 ↔ 电脑 数据互传
1. 手机端「💾 导出数据」→ 得到 `health_data_日期.json`
2. 把 JSON 发给电脑（微信 / 邮件 / 网盘）
3. 电脑打开 `desktop.html` →「📤 导入数据」选该文件
4. 数据与配置完整还原（两端格式一致，无需转换）

### 4. 查看 HTML 报告
任一端点「📄 导出报告」→ 生成 `健康数据报告_日期.html`，双击用浏览器即可查看（含统计、趋势图、明细表格）。

## ⚠️ 注意事项

1. **API 密钥安全**：请在安全的环境下配置密钥
2. **浏览器兼容性**：建议使用 Chrome、Safari、Edge 等现代浏览器
3. **联网说明**：页面可离线打开，但识别 / 抽取数据需要网络调用千问 API
4. **数据备份**：建议定期「💾 导出数据」备份 JSON

## 🔧 技术特点

- 纯 HTML/CSS/JavaScript 实现，ECharts 已内联（自包含）
- 使用 localStorage 存储数据
- 直接调用千问视觉模型（识别 + 抽取一步完成）
- 手机版与电脑版独立布局，各自适配屏幕
- 无需服务器，完全离线可运行
